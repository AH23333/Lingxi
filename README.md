# 灵犀输入法 (Lingxi IME)

Windows 端 AI 输入法，基于 **TSF（Text Services Framework）** 实现为真正的系统输入法。
当前已具备完整的拼音输入、英文补全、自学习、用户词典、快捷短语与本地 LLM 预测/重排能力，
64 位与 32 位应用均可用，全程离线，持续对标并超越系统自带的微软拼音。

## 核心能力

**拼音输入（zh-CN 配置）**
- 全拼 / 简拼 / 混拼：`jintianqi`→今天天气、`dh`→电话、`nihaoma`→你好吗。
- 整句 Viterbi 解码：按词链全局最优，而非逐字取最高频；变体质量闸拦截同音单字替换垃圾串。
- 模糊音：zh/z、ch/c、sh/s、n/l、前后鼻音等（设置可开关）。
- 隔音符：组合中打 `'` 切分音节，`xi'an`→西安（不误出"先"）。
- 候选翻页：一次最多 **60 个候选**，每页 9 个；`PageUp/PageDown`、`-`/`=`、鼠标滚轮皆可翻页；
  组合期方向键/Home/End 由 IME 接管（不会把宿主光标拽出组合区）。
- **选词联想**：中文上屏后自动弹出语境联想候选（"今天天"→"气很不错"），
  点选或按空格连续出词；打其他任何键即撤销，不劫持键盘。设置「智能」页可关。
- **部分选词保留余段**：长串中选短词（如 `nihao` 选"你"），剩余拼音留在组合里继续选，不白打。
- 末尾音节不完整也能出词（`jintianq`）；**候选窗顶部回显条**实时显示已敲拼音（掐头保尾）。
- 自学习：选过的词按次数自动置顶，跨重启保留；学习键按"实际消耗的拼音前缀"记账。
- **LLM 上下文重排（R3，默认关）**：开启后停顿打完一字时，本地小模型按已上屏上文重排 top-8；
  双上下文 KV 物理隔离、prefill 硬超时、吞吐不达标自动降级、异常熔断，LLM 文本永不进候选。
- **快打抢按空格不丢汉字**：提交键对"候选还在路上"有界等待（≤80ms），拼音侧免防抖每键即时候选。

**交互与模式**
- **中/英切换键可自定义**（设置页五态：关 / Shift / Shift或Ctrl / Ctrl / CapsLock），切换时光标附近弹"中/英"提示。
- **v 模式**：中文下首字母 `v` 直通英文（`vhello`→`hello`），遇空格/标点退出。
- **中文标点**：`,`/`.`/`;` 等自动转全角，`Shift` 出 `?`/`:` 等；`Enter` 保留原字母，`Esc` 取消组合。

**英文补全与 AI 预测（en-US / 临时英文）**
- 词中逐键补全（`mor`→more/morning），上屏替换已输入前缀；纯英文上下文只出英文候选（语言闸）。
- 上下文续写候选：本地 LLM 优先、词表兜底；复读过滤防"重复输入框已有内容"。
- 多路采样（R3 §3，默认关）：贪心+采样双路投票合并候选，seed 稳定防闪烁。

**快捷短语与符号**
- **快捷短语**：句库自定义短语可注册全局热键，一键上屏；支持手动添加与拼音自动推断。
- **符号面板**：5 分类符号/emoji，点击即上屏（Ctrl+Shift+B 全局热键默认关，避免占用应用快捷键）。

**外观**
- 五套皮肤（翠绿/青碧/橙/红/金，非蓝紫系）+ 明暗跟随系统/浅/深（候选窗与设置页）+ 候选字号 12–32 可调；
  全应用 WinUI 风格（设计令牌统一、DWM 圆角、白卡设置页）。

## 构建 / 注册 / 卸载

```cmd
cd LingxiIme
tools\build.cmd Debug        :: 构建 x64（VS2022 + MSVC + WinSDK 10.0.26100）
tools\build32.cmd            :: 构建 32 位 TIP（输出 bin\Debug32\，WOW6432Node 注册）
tools\register.cmd Debug     :: 注册（需管理员：TSF TIP 注册写 HKLM）
tools\unregister.cmd Debug --purge  :: 注销 + 清理（HKCU 设置/用户词典/临时日志）
tools\imecheck.ps1           :: 注册状态自检

:: 词库数据管线（幂等，随时可重放；fix_readings --check 已挂进 regress 闸门）
python tools\build_pinyin.py --modern-only  :: 现代词层 + 多音读音补全重放到 zh_pinyin.txt
python tools\fix_readings.py --dry          :: 只出多音缺口审计报告（tmp/readings_audit.txt），不改数据
```

注册后若输入法列表未出现"灵犀"，注销并重新登录一次 Windows。

> 三级生效模型（排查体验问题先对表）：①改词库/引擎 → 需重启常驻 `LingxiUI.exe`；
> ②改键盘/组合行为（DLL）→ 需重启目标应用（TSF 不热更驻留 DLL）；③设置项 → 即时生效。

## 设置

托盘图标：左键开/关设置窗口，右键菜单提供暂停预测（完全直通）、设置、符号面板、退出。
设置窗口（存 `HKCU\Software\LingxiIme`，修改即时生效；`--settings` 可直接打开）：

| 项 | 说明 |
|---|---|
| 拼音组合模式 | zh-CN 下字母上屏汉字；关闭则纯直通 |
| 英文逐键补全 / 候选数 | 英文前缀补全开关与条数（1–9） |
| 中英切换键 | 关 / Shift / Shift或Ctrl / Ctrl / CapsLock |
| 中文标点 / 模糊音 / v 模式 / 小鹤双拼 / 繁体输出 | 各功能开关 |
| 候选窗明暗 / 字号 / 界面配色 | 跟随系统或浅/深；12–32 号；五皮肤 |
| LLM 上下文智能重排 | **默认关**：开启后停顿打完一字时按上文重排 top-8（额外 CPU 换语序更自然） |
| LLM 多路采样 | **默认关**：重排开启时叠加双路投票，进一步提升语序质量 |
| 选词联想 | **默认开**：上屏后按语境弹联想候选，点选/空格连续出词；其他按键即撤（智能页开关） |
| 符号面板热键 | Ctrl+Shift+B 全局独占，**默认关**（避免与应用快捷键冲突） |
| 用户词典与自定义词条 | 查看/删除/导入/导出已学词条；手动加词自动推断拼音 |
| 快捷短语 | 短语库管理（编辑/删除/热键注册，保存即重注册） |

## 架构

双进程，引擎与宿主应用内存隔离：

```
ImeCore.dll（TSF 文本服务，注入宿主进程）          LingxiUI.exe（独立进程）
├─ 键盘事件处理（模式判定、Shift/v/切换键状态机）   ├─ 候选窗（置顶、圆角、拼音回显条、hover）
├─ 上下文读取（光标前 ≤300 字符，编辑会话）         ├─ 拼音引擎（词表 + Viterbi + 隔音 + 自学习）
├─ 组合期导航键接管（防宿主光标错位）       ←IPC→   ├─ 英文补全 / n-gram 续写 / 语言闸
├─ 上屏：插入 / 替换 / 部分选词保留余段             ├─ 本地 LLM（续写 + 重排 + 多路采样，均可关）
├─ 提交键候选有界等待（≤80ms，防快打丢汉字）        ├─ 设置页/符号面板/快捷短语/词典管理窗
└─ 隐藏封送窗口（鼠标选词跨线程）                   └─ 管道服务端（多客户端）+ 托盘
```

- **默认无内联组合**：不在宿主挂起 TSF 组合，从架构上避免 Chromium 类应用悬挂组合问题。
- IPC：命名管道 `\\.\pipe\lingxi-ime-ipc`，二进制帧 `[u32 len][u8 type][body]`，消息带版本号，过期丢弃。
- DLL 侧全异步，发送超时 + 失败退避，**永不阻塞宿主打字**；管道不可用时静默降级纯直通。
- 词表：`ui/engine/data/zh_pinyin.txt`（约 30 万词条 + 多音补全 + 现代词层，管线生成可重放）。

## 测试

### 引擎单元测试（engine_test）

`tools/engine_test/engine_test.cpp` 直接编译链接 `ngram.cpp` + `pinyin.cpp`，不经 TSF/IPC，纯进程内断言。
独立工程（不进 sln），输出在 `bin\enginetest\`。

```cmd
msbuild tools\engine_test\engine_test.vcxproj /p:Configuration=Release /p:Platform=x64
bin\enginetest\engine_test.exe   :: 全部 PASS 则 exit=0
```

覆盖（当前 **176 项断言**）：英文前缀补全与替换、上下文补全、中文续写（含复读过滤）、
拼音音节切分、词链/残段、简拼混拼、整句首选、口语层、模糊音容错、翻页数据、隔音符（separator 6 例）、
零声母 i/u 兜底、自学习置顶与持久化、用户词典、长句残段分池存活、多音单字可达（shei→谁 等）、
现代技术词整词（自动补全）、**选词联想**（上屏即续）、**整句变体质量闸**（首页禁垃圾变体）。
测试自带**词典 + 设置双沙盒**（APPDATA 隔离 + `LINGXI_SETTINGS_NS=test` 切基键）：
永不写用户真实词典/设置，「回归前后真实 HKCU 逐字节一致」是硬判据（PITFALLS #32/#43/#44）。
性能断言多次预热 + 中位数；安静基线 `jintianqi` <10ms（电池降频模式会漂移，见 PITFALLS #41）。

### 端到端与深度测试（e2e / deep_test）

- `tools/e2e/e2e.cpp`：合成 ITextStoreACP 宿主 + 模拟按键，覆盖激活/直通/上下文/IPC/预测/候选窗/替换上屏/续写。
- `tools/deep_test/deep_test.cpp`：拼音组合全管道场景 **T0–T17**（空格上屏、连续词、退格、标点提交、
  数字选词、翻页+第二页选词、快打抢空格、部分选词保留余段、零声母、Shift 切换、隔音、导航键、选词联想连续输出/撤销（T18），
  自带 VEH 崩溃取证与 3 轮重试壳；通过标准 = 断言全过 + 零 AV。
- `tools/regress.cmd`：一键全量回归（engine + 词库 `--check` 闸 + deep + e2e），环境沙盒 + 自有进程重启，
  日志归档 `tmp\regress-*\`。批内偶发时序红以 solo 复跑为准（PITFALLS #19/#33/#41）。

## 隐私

- 密码框等禁用 IME 的控件在 TSF 下天然不产生事件。
- 上下文仅存于两进程内存，退出即消失，不落盘、不联网。
- 本地 LLM 在本机推理，按键流永不出机。

## 已知限制

- 部分自绘光标应用光标定位可能不准（已加系统插入符兜底）；不经过 TSF 的程序（游戏 Raw Input、部分终端）无候选属预期。
- 未签名二进制，个别杀软 / SmartScreen 可能告警（无证书，签名不可行为已知结论）。
- emoji 经 GDI 灰度渲染（彩色需 DirectWrite）。
- 重建后已运行的应用继续使用旧版 DLL，需重启应用才吃到键盘侧新行为。
- 电池供电降频时引擎 latency 断言会漂移（功能断言不受影响，见 PITFALLS #41）。

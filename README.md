# 灵犀输入法 (Lingxi IME)

Windows 端 AI 输入法（路线 A：真正的 TSF 系统输入法）。当前版本：**M2 —— 直通 + 预测全链路可用**。

## 形态

第一期为"直通 + 预测"输入法：

- 激活后**按键全部直通**，英文打字行为与系统默认一致；
- 输入英文时给出**当前词补全候选**（如输入 `mor` → `morning`，上屏会替换已输入的前缀）；
- 应用里已有中英文上下文时（≥4 字符），给出**续写候选**；
- `Tab` 上屏首选，`1`-`9` 选择对应候选，`Esc`/退格关闭候选窗，鼠标点击亦可。

> M3 前的预测引擎是占位实现（小词表 + 固定中文示例候选），质量不代表最终水平。

## 构建 / 注册 / 卸载

```cmd
cd LingxiIme
tools\build.cmd            :: 构建（默认 Debug；VS2022 + MSVC + WinSDK 10.0.26100）
tools\register.cmd         :: 注册（需要管理员：CTF 的 TIP 注册 API 只写 HKLM）
tools\unregister.cmd       :: 注销（同样需要管理员）
tools\imecheck.ps1         :: 注册状态自检
```

注册后若输入法列表没有立即出现"灵犀 AI 输入法"，注销并重新登录一次 Windows。

## 使用

1. `Win + 空格` 切换到"灵犀 AI 输入法"（en-US 下主要测英文补全；zh-CN 下可测中文续写）；
2. 正常打字；在记事本输入 `mor` → 出现候选窗 → `Tab` 上屏 `morning`；
3. 先用系统拼音输入法打一句中文，切到灵犀后按一下方向键或继续输入触发上下文读取，可看到中文续写候选。

## 调试

- 全链路日志走 `OutputDebugStringW`（DebugView 可见）；
- 设环境变量 `LINGXI_LOG=1` 后，日志同时追加写入 `%TEMP%\lingxi-ime.log`（UTF-16 编码，注意用支持该编码的工具查看）。

## 自动化测试（e2e）

`tools/e2e/e2e.cpp` 是一个端到端测试宿主：实现合成文本存储（ITextStoreACP），
创建真实宿主窗口并 `AssociateFocus`，程序化激活灵犀 TIP，用 `ITfKeystrokeMgr`
模拟按键，直接断言缓冲区内容。覆盖：激活、按键直通、上下文读取、IPC、预测、
候选窗真实显示、替换式上屏、上屏后继续直通、中文续写。

```cmd
bin\Debug\e2e.exe        :: 全部 PASS 则 exit=0（会自动拉起 LingxiUI.exe）
```

注意：`ActivateLanguageProfile(zh-CN)` 在程序化激活下返回 E_INVALIDARG（系统
ctfmon 冲突），测试中对中文续写做了降级处理；zh-CN 的真实切换留给 Win+Space 手工验证。

## 架构

```
ImeCore.dll（TSF 文本服务，宿主应用进程内）        LingxiUI.exe（独立进程）
├─ 键盘事件：直通；候选可见时拦截 Tab/1-9/Esc      ├─ 候选窗（置顶、WS_EX_NOACTIVATE）
├─ 上下文读取（光标前 300 字符，编辑会话）          ├─ 预测引擎（M2 占位 → M3 n-gram → M4 LLM）
├─ 上屏：插入 / 替换前缀（编辑会话）        ←─IPC─→ ├─ 管道服务端（多客户端）
└─ 隐藏封送窗口（鼠标选词跨线程封送）               └─ 模型常驻（M4）
```

- IPC：命名管道 `\\.\pipe\lingxi-ime-ipc`，二进制帧 `[u32 len][u8 type][body]`，
  消息带上下文版本号，过期候选/上屏请求直接丢弃；
- DLL 侧全异步，发送 80ms 超时 + 500ms 失败退避，**永远不阻塞宿主打字**；
  管道不可用时静默降级为纯直通输入法。

## 隐私设计

- 密码框在 TSF 架构下天然不可见（应用禁用 IME 的控件不产生任何事件）；
- 上下文仅存于两进程的内存缓冲，进程退出即消失，不落盘、不联网；
- v1 无任何网络代码；M4 的 LLM 在本地推理，按键流永不出机。

## 已知限制（v1）

- 仅 x64 应用（32 位应用未编译对应 TIP）；
- 部分自绘光标的应用（如 Electron 内部分编辑器）光标定位可能不准；
- 某些应用不经过 TSF 处理键盘（游戏 Raw Input、部分终端），无候选功能属预期；
- 未签名二进制，个别杀软/SmartScreen 可能告警。

# 灵犀输入法 (Lingxi IME)

Windows 端 AI 输入法，基于 **TSF（Text Services Framework）** 实现为真正的系统输入法。
当前已具备完整的拼音输入、英文补全、自学习与用户词典管理能力，并在持续打磨以对标、超越系统自带的微软拼音。

## 核心能力

**拼音输入（zh-CN 配置）**
- 全拼 / 简拼 / 混拼：`jintianqi`→今天天气、`dh`→电话、`nihaoma`→你好吗。
- 整句 Viterbi 解码：按词链全局最优，而非逐字取最高频。
- 模糊音：支持 zh/z、ch/c、sh/s、n/l、前后鼻音等（可在设置中开关）。
- 候选翻页：一次返回最多 **60 个候选**，每页 9 个，`-`/`=` 或 `PageUp`/`PageDown` 翻页。
- 末尾音节不完整也能出词（`jintianq`）。
- 自学习：用户在某拼音下选过的词按次数自动置顶，跨重启保留。
- **LLM 上下文重排（R3，默认开）**：原序候选先上屏不等待；后台按已上屏上文用本地小模型
  重排 top-8 后二次刷新候选窗。prefill 硬超时 + 吞吐不达标自动降级（慢机自动退回纯频度序），
  LLM 文本永不进候选；**快打时抢按空格也不会丢汉字**——提交键对"候选还在路上"有界等待。

**交互与模式**
- **Shift 单击**：无拼音活动时在中文 / 临时英文间切换，光标附近弹出"中/英"提示。
- **v 模式**：中文模式下输入 `v` 后直接打英文（`vhello`→`hello`），遇空格/标点退出。
- **中文标点**：`,`/`.`/`;` 等自动转全角，`Shift` 出 `?`/`:` 等。
- 组合中 `Shift`+字母 / `CapsLock` 走大写英文；`Enter` 保留原字母，`Esc` 取消。

**英文补全（en-US / 临时英文）**
- 输入英文时给出当前词补全（`mor`→more/morning），上屏替换已输入前缀。
- 结合光标前上下文给出续写候选。

**用户词典管理**
- 设置窗口内可查看、删除、清空、导入、导出已学习词条；改动即时热重载，无需重启。

## 构建 / 注册 / 卸载

```cmd
cd LingxiIme
tools\build.cmd Debug      :: 构建（VS2022 + MSVC + WinSDK 10.0.26100）
tools\register.cmd Debug   :: 注册（需管理员：TSF TIP 注册写 HKLM）
tools\unregister.cmd Debug :: 注销（需管理员）
tools\imecheck.ps1         :: 注册状态自检
```

注册后若输入法列表未出现"灵犀"，注销并重新登录一次 Windows。

> 重建后已运行的应用会继续使用旧版 DLL（TSF 特性），验证新行为前需由用户重启目标应用。

## 设置

托盘图标（右下角，蓝色"灵"）：左键开/关设置窗口，右键菜单提供暂停预测（完全直通）、设置、退出。
设置窗口（存 `HKCU\Software\LingxiIme`，修改即时生效；`--settings` 可直接打开）：

| 项 | 说明 |
|---|---|
| 拼音组合模式 | zh-CN 下字母上屏汉字；关闭则纯直通 |
| 英文逐键补全 | 英文前缀补全开关 |
| 英文补全候选数 | 1–9，仅控制英文补全 |
| 候选窗明暗 | 跟随应用 / 浅色 / 深色 |
| 中文标点 | 标点自动转全角 |
| 模糊音 | 平翘舌/鼻音等容错 |
| Shift 单击切换 | 中/英文切换 |
| v 模式 | v 后直接打英文 |
| 用户词典管理 | 查看/删除/导入/导出已学词条 |

## 架构

双进程，引擎与宿主应用内存隔离：

```
ImeCore.dll（TSF 文本服务，注入宿主进程）          LingxiUI.exe（独立进程）
├─ 键盘事件处理（模式判定、Shift/v 状态机）         ├─ 候选窗（置顶、WS_EX_NOACTIVATE）
├─ 上下文读取（光标前 ≤300 字符，编辑会话）         ├─ 拼音引擎（词表 + 整句 Viterbi + 自学习）
├─ 上屏：插入 / 替换（编辑会话）            ←IPC→   ├─ 英文补全 / n-gram 续写
└─ 隐藏封送窗口（鼠标选词跨线程）                   └─ 管道服务端（多客户端）
```

- **默认无内联组合**：不在宿主内挂起 TSF 组合，从架构上避免 Chromium 类应用的悬挂组合问题。
- IPC：命名管道 `\\.\pipe\lingxi-ime-ipc`，二进制帧 `[u32 len][u8 type][body]`，消息带上下文版本号，过期请求丢弃。
- DLL 侧全异步，发送超时 + 失败退避，**永不阻塞宿主打字**；管道不可用时静默降级为纯直通。
- 词表：`ui/engine/data/zh_pinyin.txt`（约 30 万词条）。

## 测试

### 引擎单元测试（engine_test）

`tools/engine_test/engine_test.cpp` 直接编译链接 `ngram.cpp` + `pinyin.cpp`，不经 TSF/IPC，
对引擎做纯进程内断言。独立工程（不进 sln），输出在 `bin\enginetest\`，可与主构建并发编译。

```cmd
msbuild tools\engine_test\engine_test.vcxproj /p:Configuration=Release /p:Platform=x64
bin\enginetest\engine_test.exe   :: 全部 PASS 则 exit=0
```

覆盖（当前 **127 项断言**）：英文前缀补全与替换、上下文补全、中文续写、拼音音节切分、
词链/残段、简拼混拼、整句首选、口语层、模糊音容错、翻页数据、自学习置顶与跨重载持久化、
用户词典、**长句+末尾残段分池存活**。用户词典读写走 `bin\enginetest\userdata\` 沙盒，
每次运行前清空，测试既不污染真实用户词典也不被上次残留污染（幂等）。性能断言采用
**多次预热 + 逐次采样 + 中位数**，测量期临时提升线程优先级以隔离后台进程干扰：
拼音 `jintianqi` 中位数 < 10ms（实测约 0.3ms），英文上下文 < 5ms。

### 端到端与深度测试（e2e / deep_test）

- `tools/e2e/e2e.cpp`：合成文本存储（ITextStoreACP），程序化激活灵犀 TIP，用
  `ITfKeystrokeMgr` 模拟按键并断言缓冲区。覆盖激活、直通、上下文读取、IPC、预测、
  候选窗真实显示、替换式上屏、中文续写。`bin\Debug\e2e.exe` 全 PASS 则 exit=0（自动拉起 LingxiUI）。
- `tools/deep_test/deep_test.cpp`：专测拼音组合管道——空格上屏、连续词、退格、Esc、
  Enter 保留、Shift 混排、标点提交、数字选词与压力轮次；自带 VEH 崩溃取证与 3 轮重试壳。
  通过标准 = 断言全过 + 零 AV。冷启动"前台 TIP 尚未进位"的模式检测竞态由 DLL 侧有限次
  延迟重检自愈（见下"已知限制"）。
- `tools/regress.cmd`：一键全量回归（engine_test + deep_test + e2e，各带重试），跑前统一挂
  用户词典环境沙盒、每条 TSF 套件前重启自有 LingxiUI 以隔离跨套件状态串扰。日志归档
  `tmp\regress-*\`。

## 隐私

- 密码框等禁用 IME 的控件在 TSF 下天然不产生事件。
- 上下文仅存于两进程内存，退出即消失，不落盘、不联网。
- 本地 LLM 在本机推理，按键流永不出机。

## 已知限制

- 仅 x64（32 位应用的 TIP 尚未编译；可行性已核实，见 cur/GLM_EXPLORATION_R2R5.md）。
- 部分自绘光标应用光标定位可能不准；不经过 TSF 的程序（游戏 Raw Input、部分终端）无候选属预期。
- 未签名二进制，个别杀软 / SmartScreen 可能告警。
